# Dataset

The raw bearing vibration data is too large to store in this repository.

## Dataset Source
Case Western Reserve University (CWRU) Bearing Data Center

https://engineering.case.edu/bearingdatacenter/download-data-file

## Data Used
The initial analysis uses two vibration recordings:

- Normal_0: Healthy bearing
- IR007_0: Inner race fault (0.007-inch fault diameter)

## Recording Details
- Sampling frequency: 12 kHz (12,000 samples/second)
- Sensor location: Drive End (DE)
- Signal type: Vibration acceleration
- Dataset: CWRU Bearing Data Center

## Accessing the Data
Download the original MATLAB (.mat) files from the CWRU website to reproduce the analysis.

The raw dataset files are not stored in this repository due to their size.
